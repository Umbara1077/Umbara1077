The platform helps engineers respond faster with the information needed to begin investigating immediately.

### Funari Public Adjusters — AI Estimate Comparison Platform

<img src="https://dantecorso.com/images/funari-logo.png" alt="Funari Public Adjusters" width="96">

A secure client platform that compares an insurance carrier's estimate with the public adjuster's estimate.

Google Vision OCR extracts information from both PDFs. Gemini then analyzes differences in scope, line items, quantities, pricing, and totals and returns the findings as structured discrepancy data.

The system maps its findings back onto the carrier's original PDF and produces an annotated document with affected items highlighted and notes explaining what requires review or revision.

Adjusters receive:

- A structured side-by-side comparison
- An AI-generated discrepancy synopsis
- An annotated copy of the carrier’s PDF
- Highlighted items requiring review
- PDF and Excel exports for negotiation, documentation, and client reporting

`React` `Firebase` `Cloud Functions` `Google Vision OCR` `Gemini AI`

> Private client platform. No application link, client data, or internal source code is publicly available.
